# M4 安全评审清单

## 1. 身份与权限

- [x] 生产强制 RS256（`APP_ENV=production` 时拒绝 HS256 dev secret）
- [x] 5 类角色：buyer/agent/approver/ops/admin；写接口最小权限
- [x] buyer 只能查/办本人订单（工具与 API 双层校验）
- [x] 审批回调走 HMAC，不依赖用户 JWT
- [ ] 服务间调用 mTLS / 内网白名单（staging 配）
- [ ] JWT 密钥托管（KMS/secret manager）与轮换演练

## 2. 数据安全

- [x] 出口脱敏：手机号/身份证/银行卡/邮箱
- [x] 日志敏感字段打码；token 不入日志
- [x] 审计：`tool_audit`、`aftersales_transition`、`eval_run`
- [ ] 数据库静态加密/TDE（生产 DBA）
- [ ] 备份加密与异地存储（生产运维）
- [ ] 数据保留策略：会话 24h、trace TTL、备份 7/28 天（法务确认）

## 3. 输入与模型安全

- [x] 用户输入闭合标签转义（防提示注入）
- [x] 引用校验（无引用不直出）
- [x] 可答性判定（越界不硬答）
- [x] 限流 20rpm/用户 + 会话互斥
- [ ] 模型输出内容安全兜底（敏感词/合规，运营确认）

## 4. 依赖与供应链

- [x] CI trivy 镜像扫描
- [x] 依赖锁文件 `uv.lock`
- [ ] SBOM 归档与 CVE 响应流程（生产）
- [ ] 第三方 Provider 安全评估（订单/物流接口）
